REST backend

The view loads from GET /views/demo and saves every callout move with PATCH /views/demo/timelines/{timeline_id}/entries/{task_id}. The buttons below rename the view (PATCH /views/demo), and add (POST /views/demo/timelines), rename or move (PATCH /views/demo/timelines/{timeline_id}) and remove (DELETE /views/demo/timelines/{timeline_id}) timelines; click a timeline's name to select it first. The backend here is a mock running in the page, with 300 ms latency.
