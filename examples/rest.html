REST backend

The view loads from GET /views/demo and saves every callout move with PATCH /views/demo/timelines/{timeline_id}/entries/{task_id}. The buttons below rename the view (PATCH /views/demo), and add (POST /views/demo/timelines), rename or move (PATCH /views/demo/timelines/{timeline_id}) and remove (DELETE /views/demo/timelines/{timeline_id}) timelines, or make one a month longer (the same PATCH, with finish_date); click a timeline's name to select it first. "Add milestone" puts a new milestone with that name on the selected timeline (POST /views/demo/timelines/{timeline_id}/entries), and "Remove task from timeline" takes the task you clicked last off its timeline (DELETE /views/demo/timelines/{timeline_id}/entries/{task_id}). "Rename task" and "1 week later" change the task you clicked last (PATCH /views/demo/tasks/{task_id}), and "Delete task" removes it from every timeline (DELETE /views/demo/tasks/{task_id}). The marker buttons work on the marker picked in the list: add one with the name typed (POST /views/demo/markers), rename it (PATCH /views/demo/markers/{marker_id}, which also saves a dragged marker label), show it on or hide it from the selected timeline (PUT / DELETE /views/demo/timelines/{timeline_id}/markers/{marker_id}), or remove it (DELETE /views/demo/markers/{marker_id}). The backend here is a mock running in the page, with 300 ms latency.
