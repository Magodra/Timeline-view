Timeline view examples

  • Basic: one timeline with a task and a milestone callout.
  • Features: several timelines, month scale, milestone symbols, labels at different heights, a second view with absolute timelines and tasks that continue past their range, and selection with external buttons to move the selected timeline.
  • Drag in from a list: dragging tasks and milestones from a list outside the view onto it, with targetAt, highlightTarget and addEntry.
  • Built-in controls: the controls option: a menu above the heading to add timelines, × on entries, and ↑/↓ and an editable name on each timeline label.
  • Class templates: CSS classes per task, line, timeline and scale cell with timeline.templates, and custom content in task bars.
  • Pins, text templates and callout layers: entries and markers that can't be dragged, custom milestone, callout, marker and tooltip content, and your own elements on the bar's edge.
  • Task layers: your own elements on the bars, here planned periods from custom task attributes, with addTaskLayer.
  • SVG export: a download button outside the component that saves the view as SVG.
  • REST backend: loading, and saving moves and timeline changes (rename, add, reorder, remove) through the REST API (mock server).
